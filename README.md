# Harness Engineering — prova de conceito

Avaliação de adoção seletiva do ECC e de execução com Harbor. Este repositório
registra decisões e evidências; não implementa uma nova plataforma de agentes.

Snapshots upstream, backups e ambientes experimentais ficam em `.poc/`, fora
do Git. Credenciais e conteúdo dos projetos reais não pertencem a este repositório.

Nenhuma execução com LLM, instalação do Harbor ou mudança de produção está
autorizada pelo teste offline A0.
